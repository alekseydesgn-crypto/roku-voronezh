# ROKU Cyber Lounge — Воронеж

Статический сайт: HTML, CSS и JavaScript. Изображения и шрифты хранятся локально в assets/.

## Локальный просмотр

```sh
python3 -m http.server 8087 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8087/.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → /(root).
Обновления публикуются после push в main. Файл .nojekyll отключает обработку Jekyll.

Форма демонстрационная: данные не сохраняются и не отправляются. Ссылки соцсетей, окончательные комплектации, цены и контакты заполняются после подтверждения клубом.

Материалы и фирменные ресурсы предоставлены для проекта ROKU. Репозиторий не предоставляет лицензию на их стороннее использование.

## Система управления

Подготовлено подключение Pages CMS: вход `/admin/`, инструкция [CMS.md](CMS.md). Первое подключение GitHub App подтверждает владелец аккаунта. Контент хранится в `content/`, конфигурация полей — `.pages.yml`. Данные и фотографии читаются перед инициализацией сайта, исходная вёрстка служит запасной версией. Проверка: `node --test tests/cms.test.cjs`.
